# ☕ Delicia Cafe

Bienvenidos al repositorio de **Delicia Cafe**, una cafetería digitalmente diseñada con un estilo moderno, cálido y visualmente atractivo. Este sitio web fue creado con especial atención a la experiencia del usuario y diseño responsive.

---

## 🌐 Demo en vivo

👉 [Ver sitio publicado](https://rztecx.github.io/cafeteriarg/)

---

## 🧰 Tecnologías utilizadas

- HTML5
- SCSS (Sass)
- CSS3
- Git & GitHub

---

## 🚀 Funcionalidades destacadas

- Diseño totalmente **responsive** para dispositivos móviles y escritorio.
- Estética cuidada y coherente con el rubro gastronómico.
- Menú de navegación adaptable (hamburger en mobile).
- Secciones dedicadas: Sobre nosotros, Galería, Servicios y Contacto.
- Código modular con **SCSS** para mayor mantenibilidad.
